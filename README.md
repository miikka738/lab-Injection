# Secure User Lookup

Учебный проект для лабораторной работы по безопасной разработке ПО. Не для продакшена.

## Что это

Веб-приложение на FastAPI, которое делает авторизацию пользователя по логину и паролю. Сделано как безопасная версия уязвимого кода из задания Blind SQL Injection (DVWA).

## Стек

- Python 3.10+
- FastAPI
- PostgreSQL
- psycopg2-binary

## Что защищено

**SQL-инъекции.** Запросы идут через параметры (`%s`), а не через склейку строк. psycopg2 отправляет запрос и данные на сервер отдельно, поэтому через ввод нельзя подменить SQL.

**XSS.** В `views.py` все данные перед вставкой в HTML прогоняются через `html.escape`.

**Утечка информации.** Ошибки БД логируются на сервере, пользователю отдаётся просто `Internal server error`. Никаких стек-трейсов и деталей.

## Структура

- `database.py` — подключение и инициализация БД
- `main.py` — роуты и логика авторизации
- `views.py` — HTML-шаблоны и экранирование
- `setup.py` — создаёт таблицу и заливает тестовых пользователей

## Запуск

```
pip install -r requirements.txt
python setup.py
python main.py
```

Подключение к БД читается из `.env` (POSTGRES_HOST, POSTGRES_PORT, POSTGRES_DB, POSTGRES_USER, POSTGRES_PASSWORD).
